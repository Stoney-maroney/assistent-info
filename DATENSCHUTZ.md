# Datenschutzerklärung

Dieses Programm ist ein privates Tool und wird nur vom Entwickler selbst genutzt.

Es greift auf den eigenen Google-Kalender zu (Termine lesen und eintragen). Die Daten werden nur auf dem eigenen Server verarbeitet. Sie werden nicht an Dritte weitergegeben und nicht verkauft.

Der Zugriff kann jederzeit in den Google-Kontoeinstellungen widerrufen werden.
